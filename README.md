# Stock Movement Predictor - MLOps Pipeline

End-to-end MLOps pipeline for predicting 5-minute future stock movements using time-series minute-level data.

## Tech Stack
* **DVC**: Data Version Control using Google Cloud Storage (GCS)
* **Feast**: Feature Store for point-in-time correct rolling aggregations
* **MLflow**: Experiment tracking and Model Registry
* **GitHub Actions & CML**: CI pipeline and PR automated reporting
